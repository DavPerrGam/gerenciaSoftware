# Status Rafael - Sistema de Monitoreo Hospitalario

Sistema web tipo status page para visualizar el estado operativo de los sistemas tecnológicos del Hospital Universitario San Rafael de Tunja.

## Funcionalidades principales

- Portal público de monitoreo.
- Visualización del estado general del hospital.
- Visualización de más de 21 servicios tecnológicos.
- Estado individual por producto o sistema.
- Historial de incidentes.
- Login administrativo demo.
- Dashboard administrativo.
- Actualización automática cada 30 segundos.
- Clasificación de estados:
  - CONDITION_ACTIVE
  - CONDITION_WARNING
  - CONDITION_ERROR

## Tecnologías utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- LocalStorage
- GitHub
- Netlify
- Jira
